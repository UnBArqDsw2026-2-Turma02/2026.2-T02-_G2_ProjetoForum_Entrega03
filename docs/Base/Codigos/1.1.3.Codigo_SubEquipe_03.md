## Execução e demonstração

A partir de `codigo/`, com as dependências declaradas em `requirements-dev.txt` já instaladas:

```bash
python -m pytest -q
ADS_POLITICA=match_exato uvicorn subequipe3_strategy.main:app
```

Abrir `http://127.0.0.1:8000/docs` para o Swagger e os caminhos abaixo para o HTML:

| Política na inicialização | Caminho da pergunta | Resultado esperado no seed inicial |
| --- | --- | --- |
| `match_exato` | `/perguntas/00000000-0000-0000-0000-000000000065/pagina` | Curso de Python |
| `maior_saldo` | `/perguntas/00000000-0000-0000-0000-000000000065/pagina` | Comunidade Python |
| Qualquer uma das duas | `/perguntas/00000000-0000-0000-0000-000000000066/pagina` | Fórum da comunidade (fallback) |

Para comparar, parar o processo e reiniciar com `ADS_POLITICA=maior_saldo`. O seed é recriado no processo novo, permitindo comparar o mesmo estado inicial. A seleção não gera cobrança. A página registra visualização; `POST /anuncios/{anuncio_id}/cliques` registra clique e debita CPC somente se houver campanha paga elegível. IDs do seed: Curso de Python termina em `000b`, Comunidade Python em `000c`, e genérico em `001e`.
