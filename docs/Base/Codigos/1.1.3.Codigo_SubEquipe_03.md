# Código — SubEquipe_03 (GoF Comportamental: Strategy)

Código produzido pela SubEquipe_03 para o FOCO_03: o padrão **Strategy**
aplicado à seleção e exibição de anúncios do fórum. Cada política de seleção
fica em uma estratégia própria, e o Context delega a escolha sem conhecer o
algoritmo.

conhecidas estão no [README de Ads](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/blob/main/codigo/subequipe3_strategy/ads/README.md).
