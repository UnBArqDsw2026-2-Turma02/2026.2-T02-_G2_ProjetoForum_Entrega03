# Código — SubEquipe_02 (GoF Estrutural: Proxy de proteção)

Implementação toy em **Python/FastAPI** do Proxy de proteção aplicado à votação
positiva padrão. O Proxy verifica reputação e cota diária antes de delegar ao
serviço real, que registra o voto e seus efeitos. Os dados ficam em memória.

> No Docsify, os arquivos abaixo são carregados diretamente da branch `main`
> do GitHub. No GitHub, os mesmos links permitem abrir os arquivos completos.
> O relatório identifica também a versão de referência analisada.

## Participantes e componentes

| Papel | Classe ou componente | Arquivo |
| --- | --- | --- |
| Client | `ClienteVotacaoFastAPI` | `cliente.py` |
| Subject | `ServicoVotacao` | `contratos.py` |
| Proxy | `ProxyProtecaoVotacao` | `proxy.py` |
| RealSubject | `ServicoVotacaoReal` | `servico_real.py` |
| Cota diária | `CotaDiaria` e `CotaDiariaEmMemoria` | `contratos.py` e `cota.py` |
| Domínio e dados da operação | Usuário, conteúdo, solicitação, resultado, voto e evento de reputação | `dominio.py` |
| Composição e cenários | Criação dos dados e dos participantes, com a mesma cota compartilhada | `demonstracao.py` |
| Entrada HTTP e interface | API FastAPI e tela de demonstração | `app.py` e `inicio.html` |

O cliente utiliza o contrato comum `ServicoVotacao`. O Proxy exige reputação
mínima de **15** e verifica uma cota didática de **3 votos por usuário e dia UTC**.
Somente o serviço real registra os efeitos: um voto, um evento de reputação,
placar +1, reputação do autor +10 e consumo de uma unidade da cota. A reputação
do votante não muda. Nas rejeições, esses efeitos não ocorrem.

## Como executar

A aplicação e a suíte completa exigem **Python 3.11 ou superior**. No Git Bash
do Windows, a partir da raiz do repositório:

```bash
python -m venv codigo/subequipe02/.venv
codigo/subequipe02/.venv/Scripts/python.exe -m pip install -r codigo/subequipe02/requirements.txt
codigo/subequipe02/.venv/Scripts/python.exe -m uvicorn subequipe02.app:app --app-dir codigo --host 127.0.0.1 --port 8000
```

Com o ambiente preparado, basta repetir o comando do Uvicorn. Em Linux/macOS,
use `.venv/bin/python` no lugar de `.venv/Scripts/python.exe`.

- **Demonstração:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
- **Documentação interativa:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Esses endereços exigem o servidor local em execução; o GitHub Pages hospeda
somente a documentação. Mantenha o terminal aberto e use `Ctrl+C` para parar.
Execute uma aplicação por vez na porta 8000.

Na tela, prepare C01 (voto permitido), C02 (reputação insuficiente) ou C03
(cota esgotada), solicite o voto e compare os estados. Prepare novamente o
cenário antes de repetir; os dados são simulados e não persistem após reinício.

Para executar a suíte, em outro terminal na raiz do repositório:

```bash
codigo/subequipe02/.venv/Scripts/python.exe -m unittest discover -s codigo/subequipe02/tests -t codigo -v
```
