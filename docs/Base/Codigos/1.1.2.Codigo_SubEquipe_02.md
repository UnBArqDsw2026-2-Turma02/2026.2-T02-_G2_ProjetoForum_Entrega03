# Código — SubEquipe_02 (GoF Estrutural: Proxy de proteção)

Código produzido pela SubEquipe_02 para o FOCO_02: o padrão **Proxy** de
proteção aplicado à votação positiva do fórum. O Proxy verifica a reputação
do votante e a cota diária antes de delegar ao serviço real.

> Os trechos abaixo são carregados **diretamente do repositório no GitHub**.
> A página sempre mostra a versão atual de cada branch, sem cópias do
> código na documentação.

- **Relatório da subequipe:** [1.1.2. SubEquipe_02](/Base/Relatórios/1.1.2.SubEquipe_02.md)
- **Pasta no repositório (branch em revisão):** [`codigo/subequipe02/`](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/tree/feat/35-base-proxy/codigo/subequipe02)
- **Planejamento:** [Issue #18 — recorte e contexto do Proxy](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/issues/18) e [Issue #35 — base Python e Proxy](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/issues/35)
