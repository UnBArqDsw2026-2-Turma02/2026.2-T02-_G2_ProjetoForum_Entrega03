# Código — SubEquipe_01 (GoF Criacional: Factory Method)

Código produzido pela SubEquipe_01 para o FOCO_01: o padrão **Factory
Method** aplicado à criação de conteúdo do fórum (pergunta e resposta),
exposto por uma API FastAPI.

> Os trechos abaixo são carregados **diretamente do repositório no GitHub**.
> A página sempre mostra a versão atual de cada branch, sem cópias do
> código na documentação.

- **Relatório da subequipe:** [1.1.1. SubEquipe_01](/Base/Relatórios/1.1.1.SubEquipe_01.md)
- **Pasta no repositório:** [`codigo/subequipe1_factory_method/`](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/tree/main/codigo/subequipe1_factory_method)
- **Planejamento:** [Épico #1 — FOCO_01](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega03/issues/1)

## Participantes do padrão

| Papel no Factory Method | Classe | Arquivo |
| :--: | :--: | :--: |
| Product | `Conteudo` | `produtos.py` |
| ConcreteProduct | `Pergunta`, `Resposta` | `produtos.py` |
| Creator | `CriadorDeConteudo` | `criadores.py` |
| ConcreteCreator | `CriadorDePergunta`, `CriadorDeResposta` | `criadores.py` |

```shell

```
