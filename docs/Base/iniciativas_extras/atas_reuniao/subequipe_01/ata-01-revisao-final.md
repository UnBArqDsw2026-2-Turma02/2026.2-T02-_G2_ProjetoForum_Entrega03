### Resumo

Reunião de revisão final da entrega da SubEquipe 01 (GoF criacional:
Factory Method aplicado ao subdomínio Conteúdo). Com os diagramas UML do
Factory Method em tela (Figura 4, v2.0, e Figura 6, v3.0 feita no Miro), a
dupla executou a API, confirmou que o código funcionava e definiu como
demonstrá-lo: pelo Swagger, priorizando as requisições POST que usam o
Factory Method, sem rodar os testes na gravação. A revisão foi aprovada e a
gravação da apresentação foi liberada.

### Detalhes da discussão

**Revisão final e front-end.** Caio Soares abriu a gravação propondo revisar
a entrega e, se possível, criar um front-end para mostrar o código rodando
de forma mais interativa, talvez só para a parte de perguntas, como uma
página estática. Maria Laura Regis ponderou que o front-end só vale a pena
se cobrir tudo o que existe no código; caso contrário, a demonstração
mostraria menos do que foi feito. Caio Soares acrescentou que o diagrama
também não contempla um front-end.

**Execução do código.** Maria Laura Regis pediu que o código fosse
executado. Nenhum dos dois estava com o projeto aberto, e ela relatou que um
comando de limpeza de arquivos obsoletos afetou o seu ambiente, o que a
obrigou a baixar tudo de novo. Caio Soares abriu a pasta da entrega no VS
Code, e Maria Laura Regis também executou o código para testar.

**Testes.** Maria Laura Regis perguntou se os testes seriam rodados durante
a apresentação. Caio Soares respondeu que não vê necessidade: os testes
foram feitos no fluxo de TDD, ajudam no desenvolvimento com IA e servem para
garantir que a arquitetura seja respeitada. Maria Laura Regis, que também
escreveu testes, concordou. Comentou-se ainda que outras equipes também
tiveram dificuldades e que a parte de código, embora esperada, veio "meio de
repente".

**Demonstração no Swagger.** Os dois acompanharam a API no Swagger. Caio
Soares explicou que a demonstração vai mostrar como a API responde: como uma
pergunta é criada e instanciada, qual retorno ela dá e os códigos de
resposta. O mais importante é mostrar as requisições POST, porque são elas
que usam o Factory Method. Ambos confirmaram que o código e a API estavam
funcionando normalmente.

**Liberação para gravar.** Maria Laura Regis perguntou se já podiam gravar a
apresentação. Caio Soares considerou a revisão concluída: o vídeo, a
explicação e o material elaborado estavam ok. Combinaram encerrar a
gravação da revisão e começar a da apresentação.
