## Sobre

O G2_ProjetoForum é um fórum de perguntas e respostas usado como estudo de
caso na disciplina de Arquitetura e Desenho de Software (UnB), inspirado em
fóruns de programação amplamente conhecidos.

Esta é a **Entrega 03 — Desenho de Software (Padrões de Projeto)**. Cada
subequipe aplica um padrão de projeto do catálogo GoF (GAMMA et al., 2000) a
um subdomínio do fórum, com modelo UML, código funcional e vídeo do padrão em
execução, além do ponto de vista de cada integrante sobre o uso de IA
Generativa.

| Subequipe | Foco | Padrão | Subdomínio |
| :--: | :--: | :--: | :--: |
| [SubEquipe_01](/Base/Relatórios/1.1.1.SubEquipe_01.md) | GoF Criacional | Factory Method | Criação de conteúdo (pergunta e resposta) |
| [SubEquipe_02](/Base/Relatórios/1.1.2.SubEquipe_02.md) | GoF Estrutural | Proxy de proteção | Votação positiva |
| [SubEquipe_03](/Base/Relatórios/1.1.3.SubEquipe_03.md) | GoF Comportamental | Strategy | Seleção e exibição de anúncios |

O código de cada subequipe pode ser consultado no próprio site, na página
"Código" dentro da seção de cada subequipe, no menu lateral.
